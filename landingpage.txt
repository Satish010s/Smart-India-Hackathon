Design and implement a complete, production-quality landing page for an AI-powered interactive Quantum Computing learning platform.

TECH STACK
- Next.js
- JavaScript only, NOT TypeScript
- Tailwind CSS latest v4.x
- GSAP + ScrollTrigger for animations
- Lucide React for icons
- Use CSS variables / Tailwind v4 @theme for design tokens
- Fully responsive: mobile, tablet, desktop and large screens
- Dark mode + light mode with a smooth theme transition

IMPORTANT:
Do NOT create a generic SaaS landing page.
The website should feel like a premium combination of:
- modern quantum computing laboratory
- developer platform
- interactive education product
- AI-powered learning environment

The design should be clean, professional, sophisticated and technically impressive enough for a Smart India Hackathon presentation.

- subtle hover transform
- border highlight
- soft glow

- subtle floating particles

IMPORTANT:
Animations should feel premium and purposeful.
Do not make everything bounce, spin or float.
Avoid excessive animation.
Prioritize performance.

Use ScrollTrigger with:
- scrub where appropriate
- pin only for major storytelling sections
- stagger
- timeline-based animations
- responsive behavior
- reduced-motion support

Respect:
prefers-reduced-motion
